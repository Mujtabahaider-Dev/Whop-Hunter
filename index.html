Install In 3 Easy Steps

Works on Google Chrome, Brave, Arc, and Microsoft Edge.

1

Download The Zip

Download the repository zip from GitHub and extract the folder to your computer.

Whop-Hunter.zip
2

Enable Developer Mode

Open your browser extension manager and toggle on Developer Mode in the top-right.

chrome://extensions
3

Click "Load Unpacked"

Click the Load Unpacked button and choose the extracted folder. Whop Hunter is ready!
